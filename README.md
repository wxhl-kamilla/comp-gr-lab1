# Лабораторные по компьютерной графике

Нужны Visual Studio с компонентом «Разработка классических приложений на C++» и Vulkan SDK 1.4.321 или новее.

1. Распакуйте весь архив. Папки `lab1`, `lab2`, `lab3` и `external` должны оставаться рядом.
2. В Visual Studio выберите **Файл → Открыть → Папка** и откройте нужную папку: `lab1`, `lab2` или `lab3`.
3. Выберите конфигурацию **debug** и дождитесь завершения настройки CMake.
4. Выберите цель **vulkan-starter-app.exe**, выполните **Сборка → Собрать всё**, затем нажмите **Ctrl+F5**.

Для переключения на другую работу откройте её папку тем же способом. Можно использовать отдельные окна Visual Studio.

Отчёты DOCX и PDF складывайте в папку `reports` через обычный Проводник.
